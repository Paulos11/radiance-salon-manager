# Image Assets

This directory contains image assets for the Radiance Salon Manager application.

## Required Images

For the best visual experience, add the following images to this directory:

1. **hero-salon.jpg** - Main hero image for homepage (1920x1080px recommended)
   - Beautiful salon interior or happy customer getting service

2. **services-bg.jpg** - Background for services section (1920x600px recommended)
   - Salon services showcase

3. **about-bg.jpg** - Background for about section (1920x600px recommended)
   - Team or salon ambiance

## Placeholder Images

If you don't have images yet, you can use free stock photos from:
- Unsplash (https://unsplash.com/s/photos/beauty-salon)
- Pexels (https://www.pexels.com/search/beauty-salon/)
- Pixabay (https://pixabay.com/images/search/beauty-salon/)

## Format Requirements

- Format: JPG or PNG
- Max size: 500KB per image (optimized for web)
- Dimensions: As specified above for each image type
