# PROJECT ABSTRACT / SUMMARY

**Project Title:** Radiance Salon Manager
**Domain:** Web Application (MERN Stack / Full Stack)

## Statement about the Problem
In the rapidly evolving beauty and wellness industry, many salons still rely on manual booking methods (pen and paper) or fragmented digital tools that do not talk to each other. This leads to several operational inefficiencies:
1.  **Double Bookings:** Manual entry errors often result in two customers showing up for the same slot.
2.  **Inefficient Staff Management:** Difficulty in tracking staff availability and specialties leads to poor resource allocation.
3.  **Customer Inconvenience:** Clients cannot book appointments outside of business hours or view real-time availability.
4.  **Lack of Insights:** Owners lack data on popular services, revenue trends, and peak hours.

## Objective and Scope of the Project
The primary objective of the **Radiance Salon Manager** is to digitize and streamline the daily operations of a modern beauty salon.

**Objectives:**
*   To provide a seamless, 24/7 online booking interface for customers.
*   To enable real-time management of appointments, services, and staff for administrators.
*   To reduce administrative overhead and eliminate booking errors.
*   To offer a centralized platform for customer history and business performance tracking.

**Scope:**
The system is designed for small to medium-sized beauty salons. It covers:
*   **Customer Module:** Registration, Service Browsing, Real-time Availability Check, Booking, History, Cancellation.
*   **Admin Module:** comprehensive Dashboard, Staff Management, Service Catalog Management, Appointment Oversight.
*   **Authentication:** Secure Role-Based Access Control (RBAC) ensuring data security.

## Methodology
The project follows the **Agile Software Development Life Cycle (SDLC)**. This approach allowed for iterative development, continuous testing, and rapid adaptation to requirements.
*   **Requirement Analysis:** Identified key pain points in salon management.
*   **System Design:** Created ER diagrams and DFDs to model data flow.
*   **Implementation:** Developed using the MVC (Model-View-Controller) architecture.
*   **Testing:** Conducted unit, integration, and user acceptance testing (UAT).

## Hardware & Software Used
**Software Requirements:**
*   **Frontend Library:** React.js
*   **Styling:** Tailwind CSS
*   **Backend Runtime:** Node.js
*   **Web Framework:** Express.js
*   **Database:** SQLite (SQL-based relational database)
*   **IDE:** Visual Studio Code
*   **Browser:** Google Chrome (for testing)

**Hardware Requirements:**
*   Processor: Intel Core i3 or higher
*   RAM: 4GB or higher
*   Hard Disk: 10GB free space
*   Internet Connection: Required for hosting/accessing remotely

## Testing Technologies Used
*   **Jest:** For unit testing JavaScript functions.
*   **Postman:** For API endpoint verification.
*   **ESLint:** For static code analysis and ensuring code quality.
*   **Manual Black-box Testing:** For UI/UX and flow verification.

## Contribution of the Project
The Radiance Salon Manager contributes significantly to modernizing salon business operations. By automating scheduling, it frees up staff to focus on service delivery rather than administration. It improves the customer experience by offering transparency and convenience, ultimately potentially increasing business revenue and customer retention.
