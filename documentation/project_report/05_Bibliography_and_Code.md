## B. CODE SHEET GENERATION GUIDE

Per the university guidelines, you are required to attach "Printout of the Code Sheet". Since the code is extensive, it is recommended to print only the core logic files.

**Recommended Files to Print:**

1.  **Backend Core:**
    *   `backend/src/server.js` (Server entry point)
    *   `backend/src/config/database.js` (Database connection)
    *   `backend/src/controllers/appointmentController.js` (Main booking logic)

2.  **Frontend Core:**
    *   `frontend/src/App.js` (Main routing)
    *   `frontend/src/context/AuthContext.js` (Authentication logic)
    *   `frontend/src/pages/BookAppointment.js` (Booking UI logic)
    *   `frontend/src/components/ui/Button.js` (Sample reusable component)

**How to Prepare for Printing:**
1.  Open the file in VS Code.
2.  Copy the content to MS Word.
3.  Set font to **Courier New** or **Consolas**, size 10.
4.  Add a header with the File Name (e.g., `src/server.js`).
5.  Print.
